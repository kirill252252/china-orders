# China Orders - Система оформления заказов из Китая

China Orders - веб-приложение для оформления и отслеживания заказов с китайских маркетплейсов. Проект разрабатывается в рамках курсовой работы.

Система позволяет покупателям добавлять товары, оформлять заказы и следить за их статусом. Менеджеры могут обрабатывать заказы, обновлять информацию о доставке, а администраторы — управлять пользователями и настройками системы.

Поддерживаются Taobao, Tmall, 1688, Pinduoduo, JD и Poizon. В текущей версии используется тестовый провайдер для импорта товаров.

## Используемые технологии

- **Frontend:** React 18, Vite, React Router, JavaScript, CSS Modules
- **Backend:** Node.js 20, Express
- **База данных:** PostgreSQL 16
- **Кэширование:** Redis 7
- **Авторизация:** JWT и refresh-токены в httpOnly cookie
- **Валидация:** Zod
- **Безопасность:** Helmet, CORS, bcrypt, параметризованные SQL-запросы
- **Запуск:** Docker Compose

## Запуск проекта

Для запуска понадобится установленный Docker Desktop.

### 1. Подготовка

Создай файл `.env` на основе примера:

```bash
cp .env.example .env
```

При необходимости измени настройки подключения к базе данных, Redis и другие переменные окружения.

### 2. Запуск основной версии

```bash
docker compose up --build -d
```

### 3. Проверка работы

```bash
docker compose logs -f backend
```

## Запуск в режиме разработки

Для разработки предусмотрен отдельный Docker Compose-файл. В этом режиме изменения в коде применяются без необходимости каждый раз пересобирать весь проект.

```bash
docker compose -f docker-compose.dev.yml up --build -d
```

Посмотреть логи backend можно командой:

```bash
docker compose -f docker-compose.dev.yml logs -f backend
```

Frontend использует Vite с горячей перезагрузкой, а backend перезапускается при изменении файлов.

В Dockerfile для разработки настроено зеркало npm `https://registry.npmmirror.com`, чтобы ускорить установку зависимостей при проблемах с доступом к основному реестру.

## Возможности приложения

### Покупатель

- Просмотр каталога товаров, поиск и фильтрация.
- Добавление товаров по ссылке или вручную.
- Добавление товаров в корзину.
- Расчёт примерной стоимости заказа в рублях.
- Оформление заказа с тестовой оплатой.
- Просмотр своих заказов и текущих статусов.

### Менеджер

- Просмотр списка заказов, которые нужно обработать.
- Изменение статусов заказов.
- Добавление трек-номера и информации о доставке.
- Указание веса и перевозчика.
- Добавление комментариев к заказам.

### Администратор

- Управление пользователями и их ролями.
- Настройка курса юаня к рублю.
- Изменение тарифов доставки.
- Настройка комиссии.
- Просмотр статистики по заказам.

## Статусы заказов

Заказ проходит несколько этапов: от создания до получения покупателем.

```text
new
  → awaiting_payment
  → paid
  → purchased
  → shipped_from_china
  → in_transit
  → arrived_warehouse
  → delivered
```

Также предусмотрена отмена заказа. Она возможна в зависимости от текущего статуса и правил системы.

## Расчёт стоимости

Стоимость заказа рассчитывается с учётом цены товара, курса валют, комиссии и доставки:

```text
Стоимость = Цена в юанях × Курс CNY/RUB
          × (1 + Комиссия / 100)
          + Вес в кг × Тариф доставки
```

Курс валют хранится в Redis в течение одного часа. Курс, комиссия и тарифы доставки задаются через настройки администратора.

## Миграции и тестовые данные

Для обновления структуры базы данных используются миграции.

Запуск миграций:

```bash
docker compose -f docker-compose.dev.yml exec backend npm run migrate:up
```

Проверка состояния миграций:

```bash
docker compose -f docker-compose.dev.yml exec backend npm run migrate:status
```

Добавление тестовых данных:

```bash
docker compose -f docker-compose.dev.yml exec backend npm run seed
```

Откат последней миграции:

```bash
docker compose -f docker-compose.dev.yml exec backend npm run migrate:down
```
